# AURA — Missions de théorie E6

21 pages indépendantes : 20 chapitres et une initiation Bienvenue en Gestion. Chaque mission contient 3 zones, 9 énigmes et un code de 6 chiffres. Les décors sont partagés avec le jeu original dans `/assets`.

Ouvrir `missions/index.html` pour le catalogue. Chaque page de jeu se trouve dans `missions/tXcY/index.html`. Aucun service ni bibliothèque externe ne sont nécessaires ; le formulaire de résultat exige une connexion Internet.

Les questions, explications et scénarios sont dans `data.js`. Le lien du formulaire se règle dans `config.js`. Les réponses demandées dans Notion restent le prénom et le nom ainsi que le code trouvé. Le jeu n’envoie aucune donnée directement. Le code propre à la mission permet à l’enseignante de retrouver le chapitre dans sa grille de correspondance.

La progression est locale et indépendante pour chaque chapitre. Le bouton Recommencer efface seulement la mission courante, après confirmation. Les erreurs sont comptabilisées mais n’empêchent jamais de réessayer. Les indices sont facultatifs. La saisie accepte les accents et majuscules indifféremment. Les séquences se réordonnent au clavier ou avec les flèches.

L’introduction peut être passée, mise en pause ou lue sans animation. La lecture sans animation est activée par défaut si le navigateur demande une réduction des mouvements.

Le scénario et les définitions s’appuient sur les pages de cours de l’enseignante, avec des formulations reformulées pour éviter les confusions : CAF et encaisse disponible, facteur clé de succès et indicateur, plan prévisionnel et tableau historique, amortissement et paiement. Aucun support de cours existant n’est réécrit par ce dossier. La page d’initiation ne comportant pas de cours textuel exploitable, sa mission introduit les outils des chapitres voisins.
